## Core Object Model

Think DSP uses a small conceptual architecture that maps cleanly to C++:

- `Signal`: an idealized function of time. It stores parameters such as frequency, amplitude, phase offset, start frequency, or chirp end frequency. It can be evaluated at sample times.
- `Wave`: sampled data. It owns `ys` samples, a sample rate, and usually time metadata. It supports segmenting, shifting, scaling, unbiased centering, normalization, differentiation by finite difference, cumulative sum, and conversion to spectra.
- `Spectrum`: complex frequency-domain bins. Each bin stores amplitude and phase as a complex value. It supports low-pass, high-pass, band-stop, power, phase, filtering, differentiation/integration filters, and inverse transform back to a wave.
- `Spectrogram`: an ordered map from segment midpoint time to `Spectrum`, usually generated by overlapping windowed segments.

The important engineering move is to keep this model intact even when the final implementation is plain functions or framework-specific buffers.

## Chapter Map

### 0. Preface

Think DSP is programming-first. It assumes basic programming, complex numbers, light calculus, and light linear algebra. The original examples are Python with NumPy/SciPy; this skill translates the important examples to C++ patterns.

### 1. Sounds And Signals

- A signal is a quantity that varies in time. Sound is pressure variation; sampled audio is a digital approximation of that variation.
- Spectral decomposition says a signal can be represented as a sum of sinusoids.
- The DFT produces the spectrum; the FFT computes the DFT efficiently.
- A periodic signal has a period `T`; frequency is `f = 1 / T`.
- Musical timbre comes from waveform shape and harmonic amplitudes.
- `Signal.make_wave(duration, start, sampleRate)` evaluates a mathematical signal into a sampled `Wave`.
- `Wave.make_spectrum()` computes a complex spectrum. Filtering manipulates bins, then inverse transform returns a wave.

### 2. Harmonics

- Triangle waves contain odd harmonics whose amplitudes drop roughly as `1/f^2`.
- Square waves contain odd harmonics whose amplitudes drop roughly as `1/f`.
- Sawtooth waves contain even and odd harmonics whose amplitudes drop roughly as `1/f`.
- Aliasing happens when frequencies above the folding frequency, `sampleRate / 2`, become indistinguishable from lower frequencies.
- A real FFT returns bins from DC through Nyquist. Each complex bin encodes magnitude and phase.
- The DC bin, `hs[0]`, is the signal bias or mean component.

### 3. Non-Periodic Signals

- A chirp is a signal whose frequency changes over time.
- For a variable-frequency sinusoid, phase is the integral of instantaneous frequency:
  `phase[n] = phase[n-1] + 2*pi*freq[n]*dt`.
- Linear chirps change frequency by equal Hz steps. Exponential chirps change perceived pitch more evenly because musical pitch is logarithmic in frequency.
- A single spectrum hides when frequencies occurred. Use STFT/spectrograms for time-varying signals.
- Spectrogram time resolution is `segmentLength / sampleRate`; frequency resolution is `sampleRate / segmentLength`.
- The Gabor limit means improving time resolution worsens frequency resolution, and vice versa.
- DFT assumes the segment repeats periodically. If the ends do not join smoothly, spectral leakage spreads energy into nearby bins.
- Windowing, such as Hamming, tapers segment ends and reduces leakage. Half-overlap is a useful default.

### 4. Noise

- Noise can mean unwanted signal, or a signal with energy spread across many frequencies.
- White noise has equal average power at all frequencies. Uncorrelated uniform and uncorrelated Gaussian noise are both white in this spectral sense.
- Brownian/red noise is the cumulative sum of white noise. Its power spectrum falls roughly as `1/f^2`, so log power versus log frequency has slope near -2.
- Pink noise has power proportional to `1/f^beta`, with `beta` typically between 0 and 2. A simple synthesis method is white noise -> spectrum -> divide amplitudes by `f^(beta/2)` -> inverse spectrum.
- Integrated spectra show cumulative power versus frequency; white noise is approximately linear in this view.
- For Gaussian white noise, real and imaginary spectrum components are approximately Gaussian due to the Central Limit Theorem.

### 5. Autocorrelation

- Pearson correlation standardizes covariance by standard deviations and lies in `[-1, 1]`.
- Serial correlation compares a sequence with a lagged copy of itself.
- Autocorrelation evaluates serial correlation across many lags.
- Periodic signals create autocorrelation peaks at lag values that match the period. Estimate fundamental frequency as `sampleRate / peakLag`.
- Spectrum-based pitch estimation can be limited by bin spacing; autocorrelation can estimate pitch more precisely from short segments when periodicity is strong.
- Signal-processing correlation is often an unstandardized dot product; normalize deliberately when comparing results.

### 6. Discrete Cosine Transform

- Synthesis: given amplitudes and frequencies, construct a signal as a sum of cosines.
- Matrix synthesis builds `M[n,k] = cos(2*pi*t[n]*f[k])` and computes `y = M * amps`.
- Analysis solves the inverse problem: recover amplitudes from samples.
- General linear solving is expensive. With carefully chosen sample times and frequencies, the DCT matrix is orthogonal up to scale, so analysis is just a matrix transpose and scale.
- DCT-IV uses half-sample shifts in time and frequency. It is educational because inverse DCT-IV is the same transform up to scale.
- DCT-based compression segments a signal, transforms each segment, removes inaudible or small coefficients, then reconstructs with inverse DCT.

### 7. Discrete Fourier Transform

- Complex exponentials generalize sinusoids: `exp(i*phi) = cos(phi) + i*sin(phi)`.
- A complex sinusoid is `A * exp(i*(2*pi*f*t + phi0))`.
- Complex amplitude controls both magnitude and phase offset.
- DFT analysis is correlation with complex exponentials. Each bin measures similarity between the signal and one basis frequency.
- The conventional DFT does not divide by `N`; the inverse DFT divides by `N`.
- The DFT is periodic in frequency with period `N`.
- For real signals, the full DFT is conjugate-symmetric; bins above Nyquist do not add new information.

### 8. Filtering And Convolution

- Moving average smoothing is convolution with a short window.
- Convolution and cross-correlation differ by whether the window is reversed. Symmetric windows hide the difference.
- The convolution theorem: convolution in time equals multiplication in frequency.
- A time-domain window has a frequency-domain filter response.
- Boxcar/moving-average windows have sidelobes; Gaussian windows produce smoother low-pass responses.
- FFT convolution computes linear convolution efficiently if inputs are padded enough to avoid circular wrap.
- Autocorrelation can also be computed with FFTs by padding, reversing one copy, multiplying spectra, inverse transforming, and trimming.

### 9. Differentiation And Integration

- Finite difference is convolution with `[1, -1]` and behaves like a high-pass filter.
- Differentiation in time corresponds to multiplying each frequency component by `i * 2*pi*f`.
- Integration corresponds to dividing each component by `i * 2*pi*f`.
- The `f = 0` bin needs special handling. Differentiation removes DC; integration cannot infer the lost constant.
- Cumulative sum approximates integration and is the inverse of finite difference for many practical signals.
- Brownian noise has slope -2 because cumulative sum divides amplitudes by `f`, so power is divided by `f^2`.

### 10. LTI Systems

- A system maps input signals to output signals.
- A linear, time-invariant system obeys superposition and does not change behavior over time.
- An impulse contains equal magnitude at all DFT frequencies. The response to an impulse characterizes the system.
- The DFT of the impulse response is the transfer function. It stores an amplitude multiplier and phase shift for every frequency.
- Output can be computed as input convolved with impulse response, or as input spectrum multiplied by transfer function and inverse transformed.
- A room impulse response can be convolved with dry audio to simulate that room.
- Use zero-padding when frequency-domain multiplication should model linear convolution rather than circular convolution.

### 11. Modulation And Sampling

- Convolution with impulses creates shifted, scaled copies of a signal.
- Multiplication in time corresponds to convolution in frequency.
- AM radio multiplies a signal by a carrier sinusoid; in the spectrum this creates shifted copies around positive and negative carrier frequencies.
- Demodulation multiplies by the carrier again, then low-pass filters to keep the baseband copy.
- Sampling can be modeled as multiplying by an impulse train. The spectrum becomes repeated copies of the original spectrum.
- If spectral copies overlap, aliasing destroys information. Anti-alias low-pass filtering must happen before downsampling.
- A brick-wall low-pass filter corresponds to sinc interpolation in time.
- Nyquist-Shannon sampling theorem: a bandwidth-limited signal can be recovered exactly if sampled above twice its highest frequency.

## Formula Sheet

| Concept | Formula |
| --- | --- |
| Period and frequency | `f = 1 / T` |
| Phase for constant frequency | `phi(t) = 2*pi*f*t + phi0` |
| Phase from instantaneous frequency | `phi[n] = phi[n-1] + 2*pi*f[n]*dt` |
| DFT | `X[k] = sum_n x[n] * exp(-i*2*pi*k*n/N)` |
| IDFT | `x[n] = (1/N) * sum_k X[k] * exp(i*2*pi*k*n/N)` |
| Real-bin spacing | `df = sampleRate / N` |
| Nyquist/folding frequency | `sampleRate / 2` |
| Spectrogram time resolution | `segmentLength / sampleRate` |
| Spectrogram frequency resolution | `sampleRate / segmentLength` |
| Differentiation filter | `H(f) = i * 2*pi*f` |
| Integration filter | `H(f) = 1 / (i * 2*pi*f)`, except DC |
| Pink-noise amplitude filter | `H(f) = 1 / f^(beta/2)`, except DC |
| Pitch from autocorrelation | `f0 = sampleRate / bestLag` |
| Linear convolution length | `len(a) + len(b) - 1` |

## Conceptual Debugging

- If a spectrum peak appears at the wrong lower frequency, compute the folded alias before blaming the DFT.
- If a spectrum is smeared around a true tone, check segment periodicity and windowing.
- If a frequency-domain convolution has a transient wrapped to the beginning, zero-padding was insufficient.
- If an integrated signal is shifted vertically, restore the missing DC/constant term.
- If noise classification is unstable on one segment, average power spectra across segments.
- If a spectrogram misses fast changes, shorten the segment. If pitch bins are too coarse, lengthen it.
- If a real-signal DFT appears duplicated, remember conjugate symmetry around Nyquist.

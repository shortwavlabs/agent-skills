# Guitar Gear Product Shot List

Use only the shots required by the deliverable.

## Pedal standard set

1. Hero 3/4 top-front.
2. Near-front/top documentation view.
3. Rear or side connector view.
4. Footswitch/knob/material macro if needed.
5. Transparent-background ecommerce angle if requested.

## Amplifier head standard set

1. Front 3/4 hero.
2. Straight front/control panel.
3. Rear 3/4 or rear I/O.
4. Handle/corner/tolex detail.
5. Control-knob/badge detail.

## Combo or speaker cabinet standard set

1. Front 3/4 hero.
2. Straight front grille.
3. Rear view.
4. Speaker/grille detail if visible.
5. Handle/corner/caster detail.

## Consistency rules

Across a product set:

- Keep camera height and lens family consistent where practical.
- Reuse lighting rigs unless a product's finish requires a deliberate variation.
- Keep background tone and ground relationship consistent.
- Match image margins and product scale for catalog grids.
